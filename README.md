# Grupo 2 — Frontend - EcoHuella 🌱

EcoHuella es una aplicación web desarrollada como parte del proyecto de bootcamp, orientada a la visualización y futura gestión de productos sustentables y ecológicos.

Este repositorio corresponde al desarrollo del **Frontend del Hito 1**, cuyo objetivo principal es establecer la base visual, estructural y técnica de la aplicación.

---

## 📌 Hito 1

Durante este hito se trabaja principalmente en:

- Estructura inicial del proyecto.
- Configuración del entorno de desarrollo.
- Definición de la navegación principal.
- Construcción de vistas base.
- Implementación inicial de componentes reutilizables.
- Aplicación de diseño responsivo.
- Integración de lineamientos entregados por UX/UI.
- Organización inicial de rutas y módulos frontend.

En esta etapa no necesariamente se encuentran implementadas todas las funcionalidades finales del sistema.

---

## 🎯 Objetivo del proyecto

EcoHuella busca entregar una experiencia digital orientada al consumo responsable, permitiendo en etapas posteriores:

- Explorar productos sustentables.
- Visualizar información relacionada con productores.
- Gestionar compras.
- Consultar información asociada al impacto o huella verde.
- Administrar perfiles según los distintos tipos de usuario.
